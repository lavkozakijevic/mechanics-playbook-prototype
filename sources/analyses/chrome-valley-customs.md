# Pass two: tagging

## Applied tags

**Tag:** Soft Currency

**Observations:** O33

**Supporting observations:** O14, O16, O18, O26

**Confidence:** directly observed, coins are earned from every level and the episode reward and are spent on priced tasks throughout episode one

**Role:** engagement

Coins pay out from each level and are spent on the next restoration task inside the same session (O16, O18, O33).

**Rationale:** Chrome Valley Customs maintains a coin balance that rises through repeatable non-paid activity (winning puzzle levels, the episode reward) and falls when the user buys a restoration task, which satisfies the invariant. Soft Currency specializes Spendable Credits and Tokens; the more specific label is reported and the parent noted.

**Variants present:** Activity-earned soft currency; Achievement-earned soft currency (episode completion grant); Single-sink soft currency, as far as observed (restoration tasks only).

**Variants not established:** Dual-path soft currency (no coin package seen); Capped-earning, Expiring and Resetting soft currency.

**Alternative considered:** Hard Currency, rejected because no paid route adds coins in the session; if a coin package exists outside the screens seen, both labels would apply.

**Tag:** Hard Currency

**Observations:** O34, O42

**Supporting observations:** O40, O43

**Confidence:** strongly supported, gem packs sold for money and a stored gem balance are directly observed, but no exchange of gems for any result is seen in the session

**Role:** monetization

Gems are the unit sold in every shop pack and bundle (O40, O42, O43).

**Rationale:** Chrome Valley Customs sells gem packages for money that add to a displayed, stored gem balance, and presents gems as its purchasable currency. Under the presence standard the product's own currency store and balance establish the mechanic; the spending side, what gems buy, was not seen and is left undescribed. Hard Currency specializes Spendable Credits and Tokens; the more specific label is reported and the parent noted.

**Variants present:** Direct-purchase hard currency; Bundled hard currency; Earnable hard currency (gems from levels, event and episode reward); Promotional hard currency (discounted car bundle and Starter Sale).

**Variants not established:** General-purpose, Restricted and Single-sink hard currency (no sink observed); Variable-rate hard currency beyond the discounted bundles.

**Alternative considered:** Soft Currency for gems, since gems are also earned; not assigned separately because the Earnable hard currency variant covers the non-paid route on this balance. Seeing what gems are spent on would settle the description of the sink but not the classification.

**Tag:** Lives

**Observations:** O35

**Supporting observations:** O36, O40, O43
