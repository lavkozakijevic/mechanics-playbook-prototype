# Close: system view

Onboarding builds the case for frequent short movement (O2), secures the Apple Health connection the whole measure depends on (O3), and previews watts, goals and reminders before any setup (O4) (tier: directly observed). Every in-app surface sits behind the paywall, which no user passes without a plan (O23, O31) (tier: directly observed).

The Difficulty setting (O20) defines the goal, the stretch figure and the hourly cap (O26), so the level chosen there determines when the Milestone and Streak are reached (tier: strongly supported). The hourly cap (O26) and Power Hour (O27) both shape when within the day movement counts, pulling in the same direction as AI-timed reminders (O4, O5) (tier: plausible, the cap's copy states this aim while Power Hour and reminder timing were not seen in operation).
