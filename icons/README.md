## Format

PNG, square, 512x512px minimum. The site displays icons at 52px in the logo strip and 72px in the case study header, so any square image works — but 512px gives you clean rendering at all sizes and retina displays.

## Where icons appear

The logo strip on the homepage reads from this folder automatically. The case study header shows the icon in the top-left corner above the title. If an icon file is missing or fails to load, the site falls back to the app's two-letter initials on a grey background.

No registration needed in data.js. Drop the file in, name it correctly, done.
